# Task Manager - Frontend

React frontend for the Task Manager full-stack application.

## Live Demo
https://task-manager-frontend-1o56.vercel.app

## Features
- User registration and login
- Dashboard to manage tasks
- Create, update status and delete tasks
- Responsive and clean UI
- Protected routes — redirects to login if not authenticated

## Tech Stack
- React.js
- Axios
- React Router DOM
- CSS (custom styling)

## Backend Repository
https://github.com/Akshathaanandan/task-manager

## Setup Instructions
1. Clone the repo
2. npm install
3. npm start
4. Make sure backend is running on port 5000
